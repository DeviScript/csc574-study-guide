# Course Reference

Store professor-provided course materials here that should guide the study site but are not themselves rendered as part
of the site. Examples include exam philosophy, grading guidance, learning objectives, assignment expectations, and
course terminology.

When adding a source document, preserve its wording and identify its lecture, date, or original filename. Treat these
materials as authoritative when creating or revising study guides, exam questions, and flash cards.

Do not add externally sourced, historical, or user-provided supplemental materials here. Store those rendered site
materials under `csc574/additional-study-materials/` with a visible source attribution and a statement that they are not
instructor-provided or confirmed assessment content. They must not override or redefine this folder's authoritative
course references.

`CSC_574_Fall_2026_Exam_Guide_Week_1.md` is the checked-in authoritative reference for Week 1 exam philosophy,
Learning Objectives, and illustrative task prompts. Preserve the Learning Objective and nested example-task hierarchy
when using it to update exam materials.

Do not place student work, credentials, or private course material here if the public GitHub repository should not
publish it.
