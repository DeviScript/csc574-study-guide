# Course Reference

Store professor-provided course materials here that should guide the study site but are not themselves rendered as part
of the site. Examples include exam philosophy, grading guidance, learning objectives, assignment expectations, and
course terminology.

When adding a source document, preserve its wording and identify its lecture, date, or original filename. Treat these
materials as authoritative when creating or revising study guides, exam questions, and flash cards.

Do not place student work, credentials, or private course material here if the public GitHub repository should not
publish it.
