Learning objectives

  • Define cryptography, cryptanalysis, and cryptology.
  • Distinguish plaintext, ciphertext, encryption, decryption, keys, and key space.
  • Compare symmetric and asymmetric cryptography.
  • Explain Kirchhoff's principle, one-time pads, and perfect secrecy.

Cryptography foundations

Cryptography protects selected properties such as confidentiality, integrity, and authenticity. It is a toolbox rather than a complete security solution.

Keep the lecture distinctions clear: cryptography develops cryptosystems, cryptanalysis studies how to break them, and cryptology includes both.

Cryptosystems and keys

A cryptosystem maps plaintext to ciphertext with an encryption key and recovers plaintext with a decryption key. Symmetric systems use the same key; asymmetric systems use different keys.

Kirchhoff's principle requires security to depend on the secret key rather than a hidden algorithm. Key space is the set of possible key values.

Security concepts

One-time pads provide perfect secrecy only with uniformly random, message-length keys that are never reused. Information-theoretic security permits unlimited computation, while computational security depends on practical limits.

Historical ciphers illustrate key-space size and cryptanalysis, but they are not appropriate for modern systems. Do not roll your own cryptography.
